# EAMCET Career Platform - Frontend

## Setup
```bash
cd frontend
npm install
npm run dev
```

## Pages
- `/` - Landing page
- `/onboarding` - User registration
- `/assessment` - Behavioral assessment (Tinder-style cards)
- `/analysis` - Personality analysis results
- `/roadmap` - Career roadmap
- `/colleges` - College recommendations
- `/dashboard` - User dashboard

## Tech Stack
- Next.js 14 (App Router)
- React
- Tailwind CSS
- Framer Motion (animations)
